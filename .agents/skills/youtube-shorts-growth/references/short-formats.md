# SiteScoper Shorts — repeatable formats

Five formats. Rotate them. Weight future picks by signups-per-Short once we have data.

Every Short is 9:16, 1080x1920, 15–30s, captions on-screen the entire time, one CTA card at the end ("sitescoper.com — free", ~1s).

---

## 1. "I scanned [famous site] and here's what's broken"

**Why it works:** Curiosity + schadenfreude. Viewers love seeing big sites fail basic checks.

**Structure (20s):**
- 0–2s: "I ran SiteScoper on [BigSite].com" — show the URL bar typing in.
- 2–14s: Cut to 2–3 real findings with the score visible. One sentence each. Red highlights on the broken parts.
- 14–18s: One specific fix ("their hero image is 4.2MB — should be under 200KB").
- 18–20s: CTA card.

**Sample script:** "I ran SiteScoper on Notion.com. Their LCP is 4.8 seconds. They're shipping a 3MB image above the fold. And they have no meta description on /pricing. Three fixes. Fifteen minutes of work. Try it on yours — sitescoper.com."

---

## 2. "3 SEO issues costing you traffic right now"

**Why it works:** Number-led, listicle pacing, immediately actionable.

**Structure (25s):**
- 0–2s: Title card with the number, bold.
- 2–9s: Issue 1 — name it, show example, one-line fix.
- 9–16s: Issue 2.
- 16–23s: Issue 3.
- 23–25s: CTA card.

**Sample issues:** missing `<title>` on key pages, duplicate H1s, no canonical tag, 404s in the sitemap, render-blocking JS, oversized hero images, missing alt text on indexable images.

---

## 3. "Your homepage fails this 5-second test"

**Why it works:** Interactive — viewer mentally runs the test on their own site.

**Structure (15s):**
- 0–1s: "5-second test:"
- 1–4s: State the test ("Can a stranger tell what you sell in 5 seconds?")
- 4–11s: Show 2 real homepages, one pass, one fail. Big red X / green check.
- 11–14s: "SiteScoper checks this automatically."
- 14–15s: CTA card.

**Test bank:** above-the-fold value prop, single primary CTA, mobile font ≥16px, contrast ratio, first paint <2s.

---

## 4. "Before/after: fixing [one issue] in 30 seconds"

**Why it works:** Tangible transformation. Great for screen-recorded code/console proof.

**Structure (25s):**
- 0–3s: "Before:" — show the broken state (red Lighthouse score, slow load, missing tag).
- 3–18s: The fix. Show the code or setting change. Narrate one sentence.
- 18–23s: "After:" — show the new score / new behavior side-by-side.
- 23–25s: CTA card.

**Sample issues:** add `loading="lazy"`, compress hero image, add meta description, fix CLS via image dimensions, add `display: swap` to web fonts.

---

## 5. "What Lighthouse won't tell you about your site"

**Why it works:** Positions SiteScoper above the obvious tool. Devs already know Lighthouse — give them something Lighthouse misses.

**Structure (20s):**
- 0–3s: "Lighthouse said 98. But..."
- 3–16s: Show the gap. Examples: brand voice inconsistency across pages, dead internal links, thin content on money pages, missing OG tags on shared URLs, contact form actually broken.
- 16–18s: "SiteScoper catches all of this."
- 18–20s: CTA card.

**Gap bank:** semantic content quality, internal link graph, OG/Twitter previews, form deliverability, AI-readable structure, brand consistency.
